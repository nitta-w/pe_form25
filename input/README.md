# スルリム横スクロールLP「脂肪はなぜ、消えないの？」設置と差し替えガイド

納品日: 2026-07-17
確認用デモ: https://swalk-kakunin-x7k2.vercel.app （本ZIPと同一内容です）

---

## 1. 設置方法（重要）

- `index.html` と `assets/` フォルダを、**同じ階層関係のまま**サーバーにアップしてください
  （画像はすべて `assets/〜.webp` への相対パス参照です。フォルダ名の変更・階層の変更をすると画像が表示されなくなります）
- ファイル名はすべて半角英数です
  （`bg_room / bg_street / bg_gym / bg_clinic`＝背景4種、`walk_1〜4`＝歩きアニメ、`pose_1〜8`＝表情、`fat_1〜9`＝マスコット、`prop_1〜8`＝小物）
- `index.html` のファイル名は変更しても動作します
- 外部依存は Google Fonts（Zen Maru Gothic）のみ。読み込めない環境でもフォールバックフォントで動作します
- 検索エンジン除外（noindex）は付けていません。必要な場合は `<head>` 内に
  `<meta name="robots" content="noindex, nofollow">` を追加してください

## 2. 画像・動画の差し替え箇所（3種類・計9枠）

`index.html` 内を **`imgph`** で検索すると、点線ボックスのプレースホルダが3テンプレート見つかります。
`<div class="imgph">〜</div>` のブロックごと、以下のように差し替えてください。

```html
<!-- 画像の場合 -->
<img src="差し替え画像のURL" style="width:100%;border-radius:12px;display:block;margin:10px 0 4px;">
<!-- 動画の場合 -->
<video src="動画URL" style="width:100%;border-radius:12px;" autoplay muted loop playsinline></video>
```

## 3. 配信前にご確認いただきたい設定（index.html内 `CONFIG`）

| 項目 | 現在値 | 備考 |
|---|---|---|
| `BOT_BASIC_ID` | `897vblrf` | 本番のLINE公式アカウントIDかご確認ください |
| `REDIRECT_URL` | 未設定 | 設定すると `line.me` 直リンクの代わりに中継URL（計測用リダイレクタ）を経由します。`var_` パラメータはそのまま引き継がれます |
| `LP_ID` | `sururim_walk_v1` | Lステップ側での流入元判別用（変更不要） |
| 計測タグ | 未挿入 | gtag / fbq を `<head>` に挿入すると、LINEボタン押下時に `conversion` / `Lead` が自動送信されます（`openLine()` 内にフック実装済み） |
| フッターリンク | `href="#"` | 最終画面の「運営者情報」「プライバシーポリシー」のリンク先を設定してください |

## 4. Lステップ連携の仕様

- LINE友だち追加URLに `var_〇〇` 形式で回答が付与されます（既存チャット版LPと同一のフィールドID）
- 送信内容: 性別／年代／気になる部位（複数・カンマ区切り）／試したダイエット（複数）／特典／エリア／院／第1〜第3希望の日時
- 値はすべて半角です（Lステップ互換のため変更しないでください）

## 6. 動作環境メモ

- スマホ縦持ち最適化（PCでは中央にスマホ幅フレームで表示されます）
- 音はユーザーがゲートで「音あり」を選んだ場合のみ再生されます（WebAudio生成・外部音源ファイルなし）
- 画像はすべてWebP（合計約1.2MB）。初回アクセス時に主要素材を自動プリロードします
- OSの「視差効果を減らす」設定では装飾アニメーションが自動的にオフになります
